### Question 10
- **Section:** General Aptitude (GA)
- **Question Type:** Multiple Choice Question (MCQ)
- **Marks:** 2
- **Topic:** Discrete Random Variable, Expectation / Sample Mean

**Question:**
The number of patients per shift ($X$) consulting Dr. Gita in her past 100 shifts is shown in the figure. If the amount she earns is ₹ $1000(X - 0.2)$, what is the average amount (in ₹) she has earned per shift in the past 100 shifts?

*Note: The figure shown is representative.*

```
 Number of shifts
      50 |
         |                 40
      40 |                 |
         |                 |        30
      30 |                 |        |
         |        20       |        |
      20 |        |        |        |        10
         |        |        |        |        |
      10 |        |        |        |        |
         |        |        |        |        |
       0 +--------+--------+--------+--------+----
                  5        6        7        8
                     Number of patients per shift (X)
```

(A) 6,100  
(B) 6,300  
(C) 6,000  
(D) 6,500  

**Answer:**
**(A) 6,100**

**Detailed Solution:**
From the bar chart, the distribution of patients per shift over 100 shifts is:
- $X = 5$: 20 shifts
- $X = 6$: 40 shifts
- $X = 7$: 30 shifts
- $X = 8$: 10 shifts
- Total shifts $= 20 + 40 + 30 + 10 = 100$.

1. **Calculate the expected/average number of patients per shift $E[X]$:**
   $$E[X] = \frac{(5 \times 20) + (6 \times 40) + (7 \times 30) + (8 \times 10)}{100}$$
   $$E[X] = \frac{100 + 240 + 210 + 80}{100} = \frac{630}{100} = 6.3$$

2. **Calculate the average amount earned per shift:**
   $$\text{Average Earnings} = E[1000(X - 0.2)] = 1000(E[X] - 0.2)$$
   $$\text{Average Earnings} = 1000(6.3 - 0.2) = 1000 \times 6.1 = 6,100$$

### Question 11
- **Section:** Data Science and Artificial Intelligence (DA)
- **Question Type:** Multiple Choice Question (MCQ)
- **Marks:** 1
- **Topic:** Conditional Expectation, Law of Total Expectation

**Question:**
Suppose $X$ and $Y$ are random variables. The conditional expectation of $X$ given $Y$ is denoted by $E[X|Y]$. Then $E[E[X|Y]]$ equals

(A) $E[X|Y]$  
(B) $\frac{E[X]}{E[Y]}$  
(C) $E[X]$  
(D) $E[Y]$  

**Answer:**
**(C) $E[X]$**

**Detailed Solution:**
By the **Law of Total Expectation** (also known as Adam's Law or the Tower Property of conditional expectation):
$$E_Y[E_X[X | Y]] = E[X]$$

*Proof (for continuous random variables):*
$$E[E[X|Y]] = \int_{-\infty}^\infty E[X|Y=y] f_Y(y) \, dy$$
$$= \int_{-\infty}^\infty \left( \int_{-\infty}^\infty x f_{X|Y}(x|y) \, dx \right) f_Y(y) \, dy$$
$$= \int_{-\infty}^\infty \int_{-\infty}^\infty x \frac{f_{X,Y}(x, y)}{f_Y(y)} f_Y(y) \, dx \, dy$$
$$= \int_{-\infty}^\infty x \left( \int_{-\infty}^\infty f_{X,Y}(x, y) \, dy \right) dx = \int_{-\infty}^\infty x f_X(x) \, dx = E[X]$$

### Question 19
- **Section:** Data Science and Artificial Intelligence (DA)
- **Question Type:** Multiple Choice Question (MCQ)
- **Marks:** 1
- **Topic:** Cumulative Distribution Function (CDF), Median

**Question:**
Let $X$ be a continuous random variable whose cumulative distribution function (CDF) $F_X(x)$, for some $t$, is given as follows:
$$F_X(x) = \begin{cases} 0, & x \le t \\ \frac{x - t}{4 - t}, & t \le x \le 4 \\ 1, & x \ge 4 \end{cases}$$

If the median of $X$ is 3, then what is the value of $t$?

(A) 2  
(B) 1  
(C) -1  
(D) 0  

**Answer:**
**(A) 2**

**Detailed Solution:**
The median $M$ of a continuous random variable $X$ satisfies $F_X(M) = 0.5$.  
Here, given that the median $M = 3$:
$$F_X(3) = 0.5$$

Since $t \le 3 \le 4$:
$$\frac{3 - t}{4 - t} = 0.5$$
$$3 - t = 0.5(4 - t)$$
$$3 - t = 2 - 0.5t$$
$$1 = 0.5t \implies t = 2$$

### Question 20
- **Section:** Data Science and Artificial Intelligence (DA)
- **Question Type:** Multiple Choice Question (MCQ)
- **Marks:** 1
- **Topic:** Normal Distribution, Linear Transformation, Covariance

**Question:**
Let $X = aZ + b$, where $Z$ is a standard normal random variable, and $a, b$ are two unknown constants. It is given that
$$E[X] = 1, \quad E[(X - E[X])Z] = -2, \quad E[(X - E[X])^2] = 4,$$
where $E[X]$ denotes the expectation of random variable $X$. The values of $a, b$ are:

(A) $a = -2, \; b = 1$  
(B) $a = 2, \; b = -1$  
(C) $a = -2, \; b = -1$  
(D) $a = 1, \; b = 1$  

**Answer:**
**(A) $a = -2, \; b = 1$**

**Detailed Solution:**
Since $Z$ is a standard normal random variable:
$$E[Z] = 0, \quad \text{Var}(Z) = E[Z^2] = 1$$

1. **Find $b$ from $E[X]$:**
   $$X = aZ + b \implies E[X] = aE[Z] + b = a(0) + b = b$$
   Given $E[X] = 1 \implies b = 1$.

2. **Express $X - E[X]$:**
   $$X - E[X] = (aZ + b) - b = aZ$$

3. **Use $E[(X - E[X])Z] = -2$:**
   $$E[(aZ)Z] = a E[Z^2] = a(1) = a$$
   Given $E[(X - E[X])Z] = -2 \implies a = -2$.

4. **Verify with $E[(X - E[X])^2] = 4$:**
   $$E[(aZ)^2] = a^2 E[Z^2] = (-2)^2 (1) = 4 \quad \text{(Consistent)}$$

Therefore, $a = -2$ and $b = 1$.

### Question 21
- **Section:** Data Science and Artificial Intelligence (DA)
- **Question Type:** Multiple Choice Question (MCQ)
- **Marks:** 1
- **Topic:** Exponential Distribution, Parameter Estimation

**Question:**
It is given that $P(X \ge 2) = 0.25$ for an exponentially distributed random variable $X$ with $E[X] = \frac{1}{\lambda}$, where $E[X]$ denotes the expectation of $X$. What is the value of $\lambda$?  
*(ln denotes natural logarithm)*

(A) $\ln 2$  
(B) $\ln 4$  
(C) $\ln 3$  
(D) $\ln 0.25$  

**Answer:**
**(A) $\ln 2$**

**Detailed Solution:**
For an exponential random variable $X \sim \text{Exp}(\lambda)$ with PDF $f_X(x) = \lambda e^{-\lambda x}$ ($x \ge 0$):
The survival function (tail probability) is:
$$P(X \ge x) = e^{-\lambda x}$$

Given $P(X \ge 2) = 0.25$:
$$e^{-2\lambda} = 0.25 = \frac{1}{4}$$
Taking the reciprocal:
$$e^{2\lambda} = 4$$
Taking the natural logarithm on both sides:
$$2\lambda = \ln 4 = \ln(2^2) = 2 \ln 2$$
$$\lambda = \ln 2$$

### Question 26
- **Section:** Data Science and Artificial Intelligence (DA)
- **Question Type:** Multiple Select Question (MSQ)
- **Marks:** 1
- **Topic:** Bayesian Networks, Probabilistic Inference

**Question:**
Which of the following statements is/are correct in a Bayesian network?

(A) Variable elimination is an approximate inference algorithm  
(B) Gibbs sampling is an exact inference algorithm  
(C) Variable elimination is used to determine conditional probabilities  
(D) Rejection sampling is an approximate inference algorithm  

**Answer:**
**(C) and (D)**

**Detailed Solution:**
- **Statement (A):** Variable elimination is an algebraic algorithm that computes exact marginal and conditional distributions by exploiting the conditional independence properties of the network. It is an **exact** inference algorithm, not approximate. (False)
- **Statement (B):** Gibbs sampling is a Markov Chain Monte Carlo (MCMC) algorithm that generates samples from the posterior distribution. It is an **approximate** (sampling-based) inference algorithm, not exact. (False)
- **Statement (C):** Variable elimination sums out hidden/irrelevant variables to compute the exact conditional probability $P(Q | E = e)$ of query variables $Q$ given evidence $E$. (True)
- **Statement (D):** Rejection sampling is a Monte Carlo approximate inference method that generates samples from the prior network and rejects those that do not match the evidence. (True)

### Question 31
- **Section:** Data Science and Artificial Intelligence (DA)
- **Question Type:** Numerical Answer Type (NAT)
- **Marks:** 1
- **Topic:** Bayes' Theorem, Law of Total Probability

**Question:**
There are three boxes containing white balls and black balls.
- Box-1 contains 2 black and 1 white balls.
- Box-2 contains 1 black and 2 white balls.
- Box-3 contains 3 black and 3 white balls.

In a random experiment, one of these boxes is selected, where the probability of choosing Box-1 is $\frac{1}{2}$, Box-2 is $\frac{1}{6}$, and Box-3 is $\frac{1}{3}$. A ball is drawn at random from the selected box. Given that the ball drawn is white, the probability that it is drawn from Box-2 is ______ (Round off to two decimal places).

**Answer:**
**0.25** (Answer range: 0.25 to 0.25)

**Detailed Solution:**
Let $B_1, B_2, B_3$ denote the events of selecting Box-1, Box-2, and Box-3, respectively:
$$P(B_1) = \frac{1}{2}, \quad P(B_2) = \frac{1}{6}, \quad P(B_3) = \frac{1}{3}$$

Let $W$ be the event that the ball drawn is white:
- In Box-1: 2 black, 1 white (Total = 3) $\implies P(W | B_1) = \frac{1}{3}$
- In Box-2: 1 black, 2 white (Total = 3) $\implies P(W | B_2) = \frac{2}{3}$
- In Box-3: 3 black, 3 white (Total = 6) $\implies P(W | B_3) = \frac{3}{6} = \frac{1}{2}$

1. **Total Probability of drawing a white ball $P(W)$:**
   $$P(W) = P(W | B_1)P(B_1) + P(W | B_2)P(B_2) + P(W | B_3)P(B_3)$$
   $$P(W) = \left(\frac{1}{3} \times \frac{1}{2}\right) + \left(\frac{2}{3} \times \frac{1}{6}\right) + \left(\frac{1}{2} \times \frac{1}{3}\right)$$
   $$P(W) = \frac{1}{6} + \frac{2}{18} + \frac{1}{6} = \frac{3}{18} + \frac{2}{18} + \frac{3}{18} = \frac{8}{18} = \frac{4}{9}$$

2. **Bayes' Theorem for $P(B_2 | W)$:**
   $$P(B_2 | W) = \frac{P(W | B_2) P(B_2)}{P(W)} = \frac{\frac{2}{18}}{\frac{8}{18}} = \frac{2}{8} = \frac{1}{4} = 0.25$$

### Question 35
- **Section:** Data Science and Artificial Intelligence (DA)
- **Question Type:** Numerical Answer Type (NAT)
- **Marks:** 1
- **Topic:** Naïve Bayes Classifier, Misclassification Probability

**Question:**
The naive Bayes classifier is used to solve a two-class classification problem with class-labels $y_1, y_2$. Suppose the prior probabilities are $P(y_1) = \frac{1}{3}$ and $P(y_2) = \frac{2}{3}$. Assuming a discrete feature space with
$$P(x | y_1) = \frac{3}{4} \quad \text{and} \quad P(x | y_2) = \frac{1}{4}$$
for a specific feature vector $x$. The probability of misclassifying $x$ is ______ (Round off to two decimal places).

**Answer:**
**0.40** (Answer range: 0.39 to 0.41)

**Detailed Solution:**
1. **Compute joint probabilities:**
   $$P(x, y_1) = P(x | y_1) P(y_1) = \frac{3}{4} \times \frac{1}{3} = \frac{3}{12} = \frac{1}{4} = 0.25$$
   $$P(x, y_2) = P(x | y_2) P(y_2) = \frac{1}{4} \times \frac{2}{3} = \frac{2}{12} = \frac{1}{6} \approx 0.1667$$

2. **Total probability $P(x)$:**
   $$P(x) = P(x, y_1) + P(x, y_2) = \frac{3}{12} + \frac{2}{12} = \frac{5}{12}$$

3. **Compute posterior probabilities:**
   $$P(y_1 | x) = \frac{P(x, y_1)}{P(x)} = \frac{3/12}{5/12} = \frac{3}{5} = 0.60$$
   $$P(y_2 | x) = \frac{P(x, y_2)}{P(x)} = \frac{2/12}{5/12} = \frac{2}{5} = 0.40$$

4. **Decision rule and misclassification probability:**  
   Since $P(y_1 | x) = 0.60 > P(y_2 | x) = 0.40$, the classifier assigns $x$ to class $y_1$.  
   The decision is incorrect if the true class was $y_2$.  
   Therefore, the probability of error given $x$ is:
   $$P(\text{error} | x) = P(y_2 | x) = \frac{2}{5} = 0.40$$

### Question 36
- **Section:** Data Science and Artificial Intelligence (DA)
- **Question Type:** Multiple Choice Question (MCQ)
- **Marks:** 2
- **Topic:** Normal Distribution, Chi-Squared Distribution

**Question:**
Let $Y = Z^2, \; Z = \frac{X - \mu}{\sigma}$, where $X$ is a normal random variable with mean $\mu$ and variance $\sigma^2$. The variance of $Y$ is

(A) 1  
(B) 2  
(C) 3  
(D) 4  

**Answer:**
**(B) 2**

**Detailed Solution:**
- Since $X \sim \mathcal{N}(\mu, \sigma^2)$, standardizing gives:
  $$Z = \frac{X - \mu}{\sigma} \sim \mathcal{N}(0, 1)$$
- For a standard normal variable $Z$:
  $$E[Z] = 0, \quad E[Z^2] = 1, \quad E[Z^4] = 3 \quad (\text{fourth moment of standard normal})$$
- Random variable $Y = Z^2$ is the square of a standard normal variable, so $Y \sim \chi^2(1)$ (Chi-squared distribution with 1 degree of freedom).
- The variance of $Y$:
  $$\text{Var}(Y) = E[Y^2] - (E[Y])^2 = E[Z^4] - (E[Z^2])^2 = 3 - (1)^2 = 3 - 1 = 2$$
*(In general, for a Chi-squared distribution with $k$ degrees of freedom, the variance is $2k$. Here $k = 1$, so variance is $2 \times 1 = 2$.)*

### Question 39
- **Section:** Data Science and Artificial Intelligence (DA)
- **Question Type:** Multiple Choice Question (MCQ)
- **Marks:** 2
- **Topic:** Cumulative Distribution Function (CDF), Probability Calculation

**Question:**
Consider the cumulative distribution function (CDF) of a random variable $X$:
$$F_X(x) = \begin{cases} 0, & x \le -1 \\ \frac{1}{4}(x + 1)^2, & -1 \le x \le 1 \\ 1, & x \ge 1 \end{cases}$$

The value of $P(X^2 \le 0.25)$ is

(A) 0.625  
(B) 0.25  
(C) 0.5  
(D) 0.5625  

**Answer:**
**(C) 0.5**

**Detailed Solution:**
The inequality $X^2 \le 0.25$ is equivalent to:
$$-\sqrt{0.25} \le X \le \sqrt{0.25} \iff -0.5 \le X \le 0.5$$

For a continuous random variable:
$$P(-0.5 \le X \le 0.5) = F_X(0.5) - F_X(-0.5)$$

Using the formula $F_X(x) = \frac{1}{4}(x + 1)^2$ on $[-1, 1]$:
- For $x = 0.5$:
  $$F_X(0.5) = \frac{1}{4}(0.5 + 1)^2 = \frac{1}{4}(1.5)^2 = \frac{2.25}{4} = 0.5625$$
- For $x = -0.5$:
  $$F_X(-0.5) = \frac{1}{4}(-0.5 + 1)^2 = \frac{1}{4}(0.5)^2 = \frac{0.25}{4} = 0.0625$$

Subtracting the two:
$$P(X^2 \le 0.25) = 0.5625 - 0.0625 = 0.50$$

### Question 40
- **Section:** Data Science and Artificial Intelligence (DA)
- **Question Type:** Multiple Choice Question (MCQ)
- **Marks:** 2
- **Topic:** Bernoulli Distribution, Central Limit Theorem

**Question:**
A random variable $X$ is said to be distributed as $\text{Bernoulli}(\theta)$, denoted by $X \sim \text{Bernoulli}(\theta)$, if
$$P(X = 1) = \theta, \quad P(X = 0) = 1 - \theta$$
for $0 < \theta < 1$. Let $Y = \sum_{i=1}^{300} X_i$, where $X_i \sim \text{Bernoulli}(\theta), \; i = 1, 2, \dots, 300$ be independent and identically distributed random variables with $\theta = 0.25$. The value of $P(60 \le Y \le 90)$, after approximation through Central Limit Theorem, is given by
$$\text{Recall that } \Phi(x) = \frac{1}{\sqrt{2\pi}} \int_{-\infty}^x e^{-\frac{t^2}{2}} \, dt$$

(A) $\Phi(2) - \Phi(-2)$  
(B) $\Phi(1) - \Phi(-1)$  
(C) $\Phi(3) - \Phi(-3)$  
(D) $\Phi(90) - \Phi(60)$  

**Answer:**
**(A) $\Phi(2) - \Phi(-2)$**

**Detailed Solution:**
Given $n = 300$ i.i.d. Bernoulli random variables with success probability $\theta = 0.25$:
- Mean of $X_i$: $E[X_i] = \theta = 0.25$
- Variance of $X_i$: $\text{Var}(X_i) = \theta(1 - \theta) = 0.25 \times 0.75 = \frac{3}{16} = 0.1875$

For the sum $Y = \sum_{i=1}^{300} X_i$:
- Mean $\mu_Y = n\theta = 300 \times 0.25 = 75$
- Variance $\sigma_Y^2 = n\theta(1 - \theta) = 300 \times \frac{3}{16} = \frac{900}{16} = 56.25$
- Standard deviation $\sigma_Y = \sqrt{56.25} = 7.5$

By the Central Limit Theorem, $Y$ is approximately normally distributed: $Y \approx \mathcal{N}(75, 7.5^2)$.  
Standardizing the interval $60 \le Y \le 90$:
- Lower z-value:
  $$z_1 = \frac{60 - \mu_Y}{\sigma_Y} = \frac{60 - 75}{7.5} = \frac{-15}{7.5} = -2$$
- Upper z-value:
  $$z_2 = \frac{90 - \mu_Y}{\sigma_Y} = \frac{90 - 75}{7.5} = \frac{15}{7.5} = 2$$

Therefore:
$$P(60 \le Y \le 90) = \Phi(2) - \Phi(-2)$$

### Question 41
- **Section:** Data Science and Artificial Intelligence (DA)
- **Question Type:** Multiple Choice Question (MCQ)
- **Marks:** 2
- **Topic:** Exponential Distribution, Floor Transformation, Geometric Distribution

**Question:**
For $x \in \mathbb{R}$, the floor function is denoted by $f(x) = \lfloor x \rfloor$ and defined as follows
$$\lfloor x \rfloor = k, \quad k \le x < k + 1,$$
where $k$ is an integer. Let $Y = \lfloor X \rfloor$, where $X$ is an exponentially distributed random variable with mean $\frac{1}{\ln 10}$, where $\ln$ denotes natural logarithm. For any positive integer $\ell$, one can write the probability of the event $Y = \ell$ as follows
$$P(Y = \ell) = q^\ell (1 - q)$$

The value of $q$ is

(A) 0.1  
(B) 0.01  
(C) 0.5  
(D) 0.434  

**Answer:**
**(A) 0.1**

**Detailed Solution:**
$X$ is exponentially distributed with mean $E[X] = \frac{1}{\lambda} = \frac{1}{\ln 10} \implies \lambda = \ln 10$.  
The probability density function is $f_X(x) = \lambda e^{-\lambda x}$ for $x \ge 0$, and the survival function is $P(X \ge x) = e^{-\lambda x}$.

For any positive integer $\ell$:
$$Y = \lfloor X \rfloor = \ell \iff \ell \le X < \ell + 1$$
$$P(Y = \ell) = P(\ell \le X < \ell + 1) = P(X \ge \ell) - P(X \ge \ell + 1)$$
$$P(Y = \ell) = e^{-\lambda \ell} - e^{-\lambda (\ell + 1)} = e^{-\lambda \ell} (1 - e^{-\lambda}) = (e^{-\lambda})^\ell (1 - e^{-\lambda})$$

Comparing with the given expression $P(Y = \ell) = q^\ell (1 - q)$:
$$q = e^{-\lambda} = e^{-\ln 10} = \frac{1}{10} = 0.1$$

### Question 45
- **Section:** Data Science and Artificial Intelligence (DA)
- **Question Type:** Multiple Choice Question (MCQ)
- **Marks:** 2
- **Topic:** Independent Events, Complement Rule

**Question:**
A random experiment consists of throwing 100 fair dice, each die having six faces numbered 1 to 6. An event $A$ represents the set of all outcomes where at least one of the dice shows a 1. Then, $P(A) =$

(A) 0  
(B) 1  
(C) $1 - \left(\frac{5}{6}\right)^{100}$  
(D) $\left(\frac{5}{6}\right)^{100}$  

**Answer:**
**(C) $1 - \left(\frac{5}{6}\right)^{100}$**

**Detailed Solution:**
Let $A$ be the event that "at least one die shows a 1".  
The complement event $A^c$ is "none of the 100 dice shows a 1", which means every die shows a number from $\{2, 3, 4, 5, 6\}$.  
- For a single die, probability of not showing 1 is $\frac{5}{6}$.
- Since the 100 dice are tossed independently:
  $$P(A^c) = \left(\frac{5}{6}\right)^{100}$$
- By the complement rule:
  $$P(A) = 1 - P(A^c) = 1 - \left(\frac{5}{6}\right)^{100}$$

### Question 54
- **Section:** Data Science and Artificial Intelligence (DA)
- **Question Type:** Multiple Select Question (MSQ)
- **Marks:** 2
- **Topic:** Estimation Theory, Sample Mean, Unbiasedness & Variance

**Question:**
Consider a coin-toss experiment where the probability of head showing up is $p$. In the $i^{\text{th}}$ coin toss, let $X_i = 1$ if head appears, and $X_i = 0$ if tail appears. Consider
$$\hat{p} = \frac{1}{n} \sum_{i=1}^n X_i$$
where $n$ is the total number of independent coin tosses.

Which of the following statements is/are correct?

(A) $E[\hat{p}] = p$  
(B) $E[\hat{p}] = \frac{p}{n}$  
(C) As $n$ increases, variance of $\hat{p}$ decreases  
(D) Variance of $\hat{p}$ does not depend on $n$  

**Answer:**
**(A) and (C)**

**Detailed Solution:**
The indicator variables $X_1, X_2, \dots, X_n$ are independent and identically distributed Bernoulli random variables:
$$E[X_i] = p, \quad \text{Var}(X_i) = p(1 - p)$$

1. **Expectation of $\hat{p}$:**
   $$E[\hat{p}] = E\left[ \frac{1}{n} \sum_{i=1}^n X_i \right] = \frac{1}{n} \sum_{i=1}^n E[X_i] = \frac{1}{n} (n \cdot p) = p$$
   Therefore, $\hat{p}$ is an unbiased estimator of $p$.  
   $\implies$ Statement (A) is **CORRECT**, Statement (B) is **INCORRECT**.

2. **Variance of $\hat{p}$:**
   $$\text{Var}(\hat{p}) = \text{Var}\left( \frac{1}{n} \sum_{i=1}^n X_i \right) = \frac{1}{n^2} \sum_{i=1}^n \text{Var}(X_i) = \frac{1}{n^2} [n \cdot p(1 - p)] = \frac{p(1 - p)}{n}$$
   As $n \to \infty$, $\text{Var}(\hat{p}) = \frac{p(1-p)}{n} \to 0$ (decreases with rate $1/n$).  
   $\implies$ Statement (C) is **CORRECT**, Statement (D) is **INCORRECT**.

### Question 60
- **Section:** Data Science and Artificial Intelligence (DA)
- **Question Type:** Numerical Answer Type (NAT)
- **Marks:** 2
- **Topic:** Sample Covariance Matrix, Direction of Maximum Variance (PCA)

**Question:**
Let $D = \{x^{(1)}, \dots, x^{(n)}\}$ be a dataset of $n$ observations where each $x^{(i)} \in \mathbb{R}^{100}$. It is given that $\sum_{i=1}^n x^{(i)} = 0$. The covariance matrix computed from $D$ has eigenvalues $\lambda_i = 100^{2-i}, \; 1 \le i \le 100$. Let $u \in \mathbb{R}^{100}$ be the direction of maximum variance with $u^T u = 1$.

The value of
$$\frac{1}{n} \sum_{i=1}^n (u^T x^{(i)})^2 = \text{______}$$
*(Answer in integer)*

**Answer:**
**100** (Answer range: 100 to 100)

**Detailed Solution:**
Since $\sum_{i=1}^n x^{(i)} = 0$, the sample mean $\bar{x} = 0$.  
The sample covariance matrix $\Sigma \in \mathbb{R}^{100 \times 100}$ is:
$$\Sigma = \frac{1}{n} \sum_{i=1}^n (x^{(i)} - \bar{x})(x^{(i)} - \bar{x})^T = \frac{1}{n} \sum_{i=1}^n x^{(i)} (x^{(i)})^T$$

Now, consider the variance along a unit direction vector $u$ ($u^T u = 1$):
$$\frac{1}{n} \sum_{i=1}^n (u^T x^{(i)})^2 = \frac{1}{n} \sum_{i=1}^n u^T x^{(i)} (x^{(i)})^T u = u^T \left( \frac{1}{n} \sum_{i=1}^n x^{(i)} (x^{(i)})^T \right) u = u^T \Sigma u$$

In Principal Component Analysis (PCA), the direction of maximum variance $u$ corresponds to the eigenvector of $\Sigma$ associated with its largest eigenvalue:
$$\max_{u: u^T u = 1} u^T \Sigma u = \lambda_{\max}$$

The given eigenvalues are $\lambda_i = 100^{2-i}$ for $i = 1, 2, \dots, 100$:
- For $i = 1$: $\lambda_1 = 100^{2-1} = 100^1 = 100$
- For $i = 2$: $\lambda_2 = 100^{2-2} = 100^0 = 1$
- For $i \ge 3$: $\lambda_i < 1$

The largest eigenvalue is $\lambda_{\max} = \lambda_1 = 100$.  
Therefore:
$$\frac{1}{n} \sum_{i=1}^n (u^T x^{(i)})^2 = 100$$

**Question:**
A bag contains 5 white balls and 10 black balls. In a random experiment, $n$ balls are drawn from the bag one at a time with replacement. Let $S_n$ denote the total number of black balls drawn in the experiment.  
The expectation of $S_{100}$ denoted by $E[S_{100}] =$ ______ (Round off to one decimal place).

Total balls in bag $= 5 \text{ (white)} + 10 \text{ (black)} = 15$.

$$p = \frac{10}{15} = \frac{2}{3}$$

For $n = 100$ draws, the total number of black balls $S_{100}$ follows a Binomial distribution:
$$S_{100} \sim \text{Binomial}\left(n = 100, p = \frac{2}{3}\right)$$

The expected value of a binomial random variable is:
$$E[S_{100}] = n \cdot p = 100 \times \frac{2}{3} = \frac{200}{3} \approx 66.6667 \approx 66.7$$

### Question 32 (CS-1)
- **Section:** Computer Science and Information Technology (CS)
- **Question Type:** Numerical Answer Type (NAT)
- **Marks:** 1
- **Topic:** Bayes' Theorem, Conditional Probability

**Question:**
A box contains 5 coins: 4 regular coins and 1 fake coin. When a regular coin is tossed, the probability $P(\text{head}) = 0.5$ and for a fake coin, $P(\text{head}) = 1$. You pick a coin at random and toss it twice, and get two heads. The probability that the coin you have chosen is the fake coin is _______. (rounded off to two decimal places)

**Answer:**
**0.50** (Answer range: 0.49 to 0.51)

**Detailed Solution:**
Let $F$ be the event of choosing the fake coin, and $R$ be the event of choosing a regular coin:
$$P(F) = \frac{1}{5} = 0.2, \quad P(R) = \frac{4}{5} = 0.8$$

Let $HH$ be the event of observing two heads in two tosses of the chosen coin:
- For the fake coin: $P(HH | F) = 1 \times 1 = 1$.
- For a regular coin: $P(HH | R) = 0.5 \times 0.5 = 0.25$.

Total probability $P(HH)$:
$$P(HH) = P(HH | F) P(F) + P(HH | R) P(R) = (1 \times 0.2) + (0.25 \times 0.8) = 0.2 + 0.2 = 0.4$$

By Bayes' Theorem:
$$P(F | HH) = \frac{P(HH | F) P(F)}{P(HH)} = \frac{0.2}{0.4} = 0.50$$

Suppose a 5-bit message is transmitted from a source to a destination through a noisy channel. The probability that a bit of the message gets flipped during transmission is 0.01. $$P(\text{error-free}) = (0.99)^5 \approx 0.95099 \approx 0.951$$

### Question 58 (CS-1)
- **Section:** Computer Science and Information Technology (CS)
- **Question Type:** Numerical Answer Type (NAT)
- **Marks:** 2
- **Topic:** Continuous Random Variable, Probability Density Function

**Question:**
Consider a probability distribution given by the density function $P(x)$:
$$P(x) = \begin{cases} Cx^2, & \text{for } 1 \le x \le 4 \\ 0, & \text{for } x < 1 \text{ or } x > 4 \end{cases}$$
The probability that $x$ lies between 2 and 3, i.e., $P(2 \le x \le 3)$ is __________. (rounded off to three decimal places)

**Answer:**
**0.302** (Answer range: 0.300 to 0.302)

**Detailed Solution:**
1. **Find normalizing constant $C$:**
   $$\int_1^4 P(x) \, dx = 1 \implies C \int_1^4 x^2 \, dx = 1$$
   $$C \left[ \frac{x^3}{3} \right]_1^4 = C \left( \frac{64 - 1}{3} \right) = C \left( \frac{63}{3} \right) = 21C = 1 \implies C = \frac{1}{21}$$

2. **Calculate $P(2 \le x \le 3)$:**
   $$P(2 \le x \le 3) = \int_2^3 C x^2 \, dx = \frac{1}{21} \left[ \frac{x^3}{3} \right]_2^3 = \frac{1}{21} \left( \frac{27 - 8}{3} \right) = \frac{1}{21} \times \frac{19}{3} = \frac{19}{63} \approx 0.301587 \approx 0.302$$
